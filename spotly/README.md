# Spotly

## Spotly — Plataforma de Aparcamiento Inteligente

Spotly es una plataforma de aparcamiento inteligente diseñada para mostrar en tiempo real el estado de las plazas de aparcamiento en la vía pública. El sistema permite a cualquier usuario saber, antes de salir de casa, si hay plazas disponibles en su destino, eliminando el tiempo perdido dando vueltas buscando aparcamiento.

La plataforma combina visión artificial, infraestructura cloud privada y una aplicación móvil en un sistema completamente integrado. Una cámara instalada en la vía pública captura imágenes de las plazas de aparcamiento. Un modelo de detección basado en YOLO y OpenCV analiza cada frame en tiempo real e identifica si cada plaza está ocupada o libre. Cuando el estado de una plaza cambia, el sistema lo comunica al backend en menos de un segundo, y la aplicación móvil del usuario se actualiza de forma instantánea sin necesidad de recargar la página.

Lo que diferencia a Spotly de soluciones similares es que toda la infraestructura que lo sustenta ha sido construida desde cero sobre hardware físico del laboratorio, sin depender de ningún proveedor de nube pública. El cluster que gestiona las máquinas virtuales, el almacenamiento distribuido, las redes virtuales, el firewall, el sistema de monitorización y el pipeline de backup son operados íntegramente por el equipo. Esto convierte a Spotly no solo en una aplicación funcional, sino en una demostración completa de cómo se diseña, despliega y opera una infraestructura privada de nivel profesional.

El sistema está diseñado siguiendo una arquitectura en capas con separación estricta de responsabilidades. La capa de red segmenta el tráfico mediante VLANs gestionadas por un firewall OPNsense, garantizando que cada tipo de comunicación viaje de forma aislada. La capa de virtualización ejecuta cada servicio en su propia máquina virtual dentro de un cluster MicroCloud de tres nodos con alta disponibilidad y replicación automática de datos. La capa de aplicación organiza los servicios en redes virtuales OVN independientes según su función — DMZ, aplicación e infraestructura — de modo que ningún servicio expuesto al exterior tiene acceso directo a la base de datos o a los sistemas internos. La conectividad exterior se gestiona mediante un túnel Cloudflare que expone la aplicación bajo el dominio `app.spotly.cat` sin necesidad de abrir puertos en el firewall institucional.

Spotly es el resultado de un trabajo de tres personas — infraestructura, backend/vision artificial y automatización — que han construido conjuntamente un sistema funcional, seguro y documentado, enfrentando y resolviendo problemas reales de redes, almacenamiento, virtualización y despliegue que van mucho más allá del alcance habitual de un proyecto de fin de curso.
